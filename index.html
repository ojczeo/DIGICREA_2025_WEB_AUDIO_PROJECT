📖 How to Use the Synthesizer

Controls

  • Keyboard Control: Enable the toggle and press W, X, C, V keys to change frequency of the 1st oscillator
  • Mouse Control: Enable the toggle and move your mouse to change frequency and frequency modulation of the 1st oscillator
  • Oscillators: Two independent oscillators with frequency, type (sine/square/sawtooth/triangle), and LFO controls
  • Filters: High-pass (HPF) and Low-pass (LPF) filters to shape the sound
  • Effects: Distortion, Delay, and Reverb with on/off toggles and parameter controls

Presets

  • Save: Enter a preset name and click Save (button changes to Override if name exists)
  • Load: Select a preset from the dropdown and click Load
  • Delete: Select a preset and click Delete to remove it
  • Download All: Export all presets to a JSON file
  • Upload: Import presets from a JSON file (duplicates are renamed automatically)
