📖 How to Use the Synthesizer

Controls

  • Start audio: Click the ▶️ button once to unlock audio; use the same button to pause/resume.
  • Keyboard control: Toggle on. Use Z/X to nudge OSC1 −/+10 Hz and C/V to nudge OSC2 −/+10 Hz within each slider’s range.
  • Mouse control: Toggle on; the full browser window maps to frequency (vertical) and LFO rate (horizontal). Choose which oscillators react via the OSC1/OSC2 mouse switches; input fields are ignored so typing doesn’t change audio.
  • Oscillators: Each oscillator has on/off, frequency slider, waveform type (sine/square/saw/triangle), and LFO rate/toggle.
  • Visualizers: Use the 📊 switch in the bottom-right of each canvas to swap waveform ↔ spectrum; +/− zoom controls sit in the top-right.
  • Master: Master level slider plus its own 📊 toggle and zoom to inspect the mixed signal.
  • Filters: High-pass (HPF) and Low-pass (LPF) sliders shape the tone.
  • Effects: Distortion (level), Delay (time/feedback), Reverb (mix) with individual toggles.
  • Routing: Click 🔀 Routing to open the live signal-flow diagram; close with the ✖️ button or by clicking outside.

Presets

  • Save: Enter a preset name and click Save (button changes to Override if name exists)
  • Load: Select a preset from the dropdown and click Load
  • Delete: Select a preset and click Delete to remove it
  • Download All: Export all presets to a JSON file
  • Upload: Import presets from a JSON file (duplicates are renamed automatically)
